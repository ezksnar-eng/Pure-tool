3. خط الإنتاج (Pipeline)

تُعالَج كل صورة عبر هذه المراحل. المرحلة الرابعة (التصنيف) هي ما يمنع تبييض/ترجمة المؤثرات الصوتية والعلامات المائية بالخطأ.

  1. تحضير الصورة
    تحسين تباين + نسخة مصغّرة سريعة لفحص OCR
    بالانتظار
  2. كشف واستخراج النص
    Tesseract.js مع درجة ثقة لكل كلمة
    بالانتظار
  3. تجميع الفقاعات
    دمج الكلمات المتقاربة لتكوين وحدات نصية
    بالانتظار
  4. تصنيف المحتوى
    حوار حقيقي / مؤثر صوتي / علامة مائية / ضوضاء
    بالانتظار
  5. إزالة العلامات المائية
    تلقائي بالكلمات المفتاحية + يدوي إن وُجد
    بالانتظار
  6. تبييض الحوار فقط
    حساب لون الخلفية بالوسيط (median) لتفادي الألوان الخاطئة
    بالانتظار
  7. الترجمة
    فقاعات الحوار الحقيقية فقط
    بالانتظار
  8. التنضيد
    لف النص المترجم داخل الفقاعة المنظّفة
    بالانتظار
  9. التصدير والإحصائيات
    ZIP + أرقام حقيقية فقط
    بالانتظار
لم يبدأ التشغيل بعد

4. إزالة علامة مائية يدوياً (لشعارات/رسومات لا يلتقطها OCR)

اختر صورة، ثم ارسم مربعاً فوق العلامة المائية واضغط "امسح المنطقة". يمكن تطبيق نفس الإحداثيات على كل الصفحات دفعة واحدة إذا كانت العلامة بنفس المكان في كل الصور.
